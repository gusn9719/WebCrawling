# 한국어 불용어 사전 (리뷰 도메인)
# - 수업(0526)에서 NLTK 영어 stopwords 대신 직접 만든 목록을 썼던 방식 그대로
# - "#" 으로 시작하는 줄과 빈 줄은 주석으로 무시
# - 한 줄에 단어 하나
#
# 선정 기준:
#   1) 조사/대명사: 는, 도, 을, 그, 저, 이
#   2) 의미 없는 부사: 좀, 막, 약간, 매우, 진짜, 정말, 너무
#      (감성을 가지는 듯 보이지만 RNN 입력에서는 노이즈에 가깝다.
#       "정말 좋다" 의 신호는 "좋다" 가 충분히 들고 있음)
#   3) 리뷰 상투어: 사용, 제품, 구매, 후기, 리뷰
#      (모든 클래스에 공통으로 나와 분류 신호가 0 에 가깝다)
#   4) 형태소 잔여물: 거, 것, 수, 등, 좀
