# 2026-06-15 Worklog

## BiLSTM 정식 실험 준비

- 이전 BiLSTM 결과는 `epochs=1` smoke test였으므로 최종 성능으로 해석하지 않기로 했다.
- 정식 비교를 위해 `epochs=3` 과 validation loss 기준 EarlyStopping을 사용한다.
- EarlyStopping은 과도한 학습 시간을 줄이면서 validation 기준으로 가장 나은 가중치를 복원하기 위해 적용한다.
- 클래스 불균형 영향을 계속 비교하기 위해 `class_weight=none` 과 `class_weight=balanced` 실험을 모두 유지한다.
- 새 실험 결과는 기존 `lstm_none`, `lstm_balanced` 리포트를 덮어쓰지 않고 별도 run name으로 저장한다.
- 결과 해석은 검수 후 README에 반영하고, 현재 단계에서는 학습 산출물과 지표 확인에 집중한다.
