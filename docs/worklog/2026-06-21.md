### 오늘 - PowerShell 한국어 인코딩 주의사항 CLAUDE.md에 추가

#### What changed

- `CLAUDE.md` Gotchas 섹션 끝에 PowerShell 인코딩 경고 추가.

#### Why

- PowerShell `Get-Content`는 시스템 기본 인코딩(CP949)으로 읽고, `Set-Content`는 별도 지정 없으면 UTF-16 LE로 쓴다.
- 이 조합으로 한국어 JSONL/CSV를 파이프 처리하면 문자가 손상된다.
- 코드 변경은 없고, 재발 방지를 위한 문서 추가만 함.

#### Files touched

- `CLAUDE.md` — Gotchas 섹션에 4줄 경고 추가

#### Decisions

- Decision: 코드 수정 없이 CLAUDE.md 문서만 추가
  - Reason: 현재 크롤러 코드는 Python만 파일 I/O를 하므로 직접적인 버그 없음
  - Alternatives considered: `.editorconfig` 생성
  - Why rejected: `.editorconfig`는 에디터 동작 설정이며 PowerShell 런타임 인코딩과 무관

#### Verification

- [x] Code reviewed

- [x] Manual check completed

#### Remaining work

- 없음

#### Risks / Notes
