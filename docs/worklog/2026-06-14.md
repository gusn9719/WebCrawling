# 2026-06-14 Worklog

## 감성 분석 학습 설계

- 별점만으로 라벨을 만들면 실제 리뷰 본문과 맞지 않는 사례가 생길 수 있어, 별점은 초기 후보 라벨로만 보고 본문 감성 단서와 함께 판단하는 흐름으로 정리했다.
- 리뷰 본문에는 "트러블이 없다", "자극 없이"처럼 부정 단어가 긍정 의미로 쓰이는 표현도 있으므로, 본문 단서를 함께 확인해 라벨 충돌 가능성을 줄였다.
- `mixed`는 긍정/부정 단서가 섞인 본문을 표시하는 중간 판정으로 보고, 최종 학습 클래스에는 포함하지 않았다.
- 별점 후보와 본문 감성 단서가 강하게 충돌하거나 mixed로 판단된 리뷰는 `ambiguous`로 분리하고 학습에서 제외했다.
- 최종 클래스는 과제 흐름과 평가 해석을 단순하게 유지하기 위해 `negative`, `neutral`, `positive` 3개로 고정했다.
- 모델 입력에는 `rating`, `score`, `star` 등 별점 관련 컬럼을 쓰지 않는다. 모델이 별점 숫자를 보고 정답을 맞히는 구조가 되면 리뷰 텍스트 감성 분석으로 보기 어렵기 때문이다.
- 클래스 분포가 positive 쪽으로 크게 치우쳐 있어 accuracy만 보면 minority class 성능을 놓칠 수 있다. macro F1, class별 recall, 특히 neutral recall을 함께 확인한다.
- LSTM 성능을 해석하려면 단순하고 강한 비교 기준이 필요하므로 TF-IDF + LogisticRegression baseline을 먼저 둔다.
- 리뷰 문장은 앞뒤 표현이 함께 의미를 만드는 경우가 많아 단방향 LSTM보다 BiLSTM을 1차 주 모델로 선택했다.
- class imbalance 영향을 확인하기 위해 class_weight 미적용/적용 결과를 비교한다.
- Attention-BiLSTM과 CNN-BiLSTM은 1차 구현 이후 baseline과 BiLSTM 결과를 확인한 뒤 검토할 개선 실험으로 남긴다.
- 현재 단계의 목표는 복잡한 모델 확장이 아니라 clean baseline 성능을 확인하는 것이다.
