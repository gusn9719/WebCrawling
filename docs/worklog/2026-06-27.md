## 정규화 규칙 요약

### normalize_skin_type

- 구분자: `re.split(r"\s*·\s*", text)` — 공백 변형 허용
- 첫 토큰이 기본 피부 타입(지성/건성/민감성/복합성/중성)일 때만 `base_skin_type` 인정
- 첫 토큰이 기본 피부 타입이 아니면 → `no_base_skin_type`, 전 토큰을 `skin_need_tags`로 처리
- 결측값(None, float NaN, pd.NA, "", "nan") → `missing`
- 정규화 맵: 여드름 → 트러블, 유수분조절 → 유수분 조절
- "/" 포함 토큰은 분리 후 각각 정규화 (진정/보습 → [진정, 보습])

### normalize_skin_concern

- 구분자: `re.split(r"\s*,\s*", text)` — 공백 변형 허용
- `^C\d+$` 패턴 토큰 → `skin_concern_codes` (의미 추측 안 함)
- 나머지 → "/" 분리 + 정규화 맵 적용 → `skin_concern_tags`
- tags 있으면 `ok`, codes만 있으면 `code_only`, 둘 다 없으면 `missing`
