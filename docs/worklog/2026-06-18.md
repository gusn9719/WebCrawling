#### Decisions

- Decision: Use `klue/bert-base`, `clean_review`, `epochs=3`, `lr=2e-5`, `batch_size=16`, `max_length=160`, and balanced cross entropy as defaults.
  - Reason: These are conservative BERT fine-tuning defaults for Korean text under class imbalance.
  - Alternatives considered: continue only with BiLSTM, use `tokens_str`, use no class weighting, or start with a review-specific ELECTRA checkpoint.
  - Why rejected: The project needs a modern baseline first; Transformer tokenizers should see natural text; previous experiments showed neutral recall collapse without imbalance handling; ELECTRA can be a later comparison.
